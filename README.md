## 🚀 How to Run & Preview

### Option 1: Instant Double-Click (Zero Setup)
Simply double-click `index.html` in your file explorer to open it immediately in Google Chrome, Microsoft Edge, or any web browser.

### Option 2: Local Web Server
If you have Node.js or Python installed, you can run:

```bash
# Using Node.js
npm start
# OR: npx serve -l 3000

# Using Python
python -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.

## 🌐 Free 1-Click Deployment (Vercel / GitHub Pages / Netlify)

### To deploy on GitHub Pages:
1. Initialize git and push to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Sumayya Cinematic Portfolio"
   git branch -M main
   git remote add origin https://github.com/sumayyasiraj/<repo-name>.git
   git push -u origin main
   ```
2. Go to **Repository Settings** > **Pages** > Select `main` branch > Click **Save**.
3. Your portfolio will be live at `https://sumayyasiraj.github.io/<repo-name>/`!

### To deploy on Vercel:
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` in this directory and press Enter for default options.
3. Your portfolio is instantly live on a custom URL with free SSL!
